# Homepage Prototype v0.1

An interactive homepage direction study for Alfie's product design portfolio.

- All project copy, metrics, product interfaces, and contact details are fictional or anonymized placeholders.
- The prototype evaluates layout, hierarchy, responsive behavior, glassmorphism, and micro-interactions.
- Case-study pages, the final design system, real resume, and production content are outside this version.
- Aspekta is used under SIL OFL 1.1; the license is included in `dist/assets/fonts/LICENSE.txt`.

The public preview is generated from the static files in `dist/`.
